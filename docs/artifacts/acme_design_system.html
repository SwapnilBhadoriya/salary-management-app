Design principles

Clarity over cleverness

Every element earns its place. No decorative chrome. Data is the UI — everything else recedes.

Comfort at scale

10,000 rows demands breathing room. Generous row height, clear hierarchy, eyes don't strain after 30 minutes.

Progressive disclosure

List → profile → history. Actions surface when relevant. Nothing competes for attention it hasn't earned.

Trustworthy by default

Compensation data is sensitive. Conservative palette, no playfulness, every action is explicit and reversible.

Color palette — semantic tokens

All colors adapt automatically in light and dark mode via CSS variables.

Accessibility guidelines

Color contrast: All text meets WCAG AA (4.5:1 body, 3:1 large). Salary amounts in mono font at 13px pass independently. Status is never conveyed by color alone — always paired with an icon or label.

Keyboard navigation: Full tab order through table rows, filter controls, and action buttons. Escape closes any open dialog. Arrow keys navigate within dropdowns and select menus.

Screen reader support: All tables have role="table" with proper aria-label. Sort buttons announce sort direction. Loading states use aria-live="polite". Avatars are aria-hidden.

Focus management: Visible focus ring on all interactive elements using --focus-shadow. Dialog opens focus trap. On close, focus returns to trigger element.

Zoom & resize: Layout reflows gracefully at 200% browser zoom. No horizontal scroll at 1280px+ viewport. Minimum touch target 44×44px on interactive elements.
